# Elroi Terminal — מסוף גרפים עצמאי בסגנון TradingView

מערכת גרפים עצמאית (מניות / קריפטו / פורקס), חינמית לחלוטין.

## מה יש כאן
- גרף חי עם Lightweight Charts (המנוע של TradingView, קוד פתוח)
- טיים-פריימים: דקה עד חודש · סוגי גרף: נרות, ברים, קו, אזור, בייסליין, הייקין-אשי
- כלי ציור: קו מגמה, קו אופקי, פיבונאצ'י, טקסט, מגנט
- אינדיקטורים מובנים: SMA, EMA, בולינגר, VWAP, Volume, RSI, MACD
- רשימת מעקב עם מחירים חיים · חיפוש סמלים · שמירת פריסות
- מנוע התראות שרת-side: חוקי מחיר/אינדיקטור (SMA, EMA, RSI, MACD, בולינגר), תדירות ותפוגה, התראת טלגרם
- ✨ יצירת אינדיקטורים ב-AI (Hugging Face, מסלול חינמי) — כותב קוד לפי תיאור בעברית ומטמיע ישירות בגרף
- קריפטו בזמן אמת (WebSocket חינמי של Coinbase, בלי מפתח)

## מקורות נתונים (חינמיים)
| שוק | מקור | רמת עדכניות |
|---|---|---|
| קריפטו | Coinbase -> Kraken | זמן אמת |
| פורקס יומי | Frankfurter (ECB) | יומי |
| מניות / תוך-יומי | Yahoo Finance | דיליי ~15 דקות |

## הרצה מקומית
pip install -r requirements.txt
uvicorn server:app --port 8000
